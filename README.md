# battleship-rl

This repository contains the trained Battleship AI policy and a React web app that uses it.

## What's inside

- `ai_policy.json` — Generated by the PyTorch DQN trainer in Google Colab. It maps board states to the Teacher's recommended shots.
- `web/` — A React + Vite web app that loads `ai_policy.json` and uses it to power the computer opponent.

## Web app

```bash
cd web
npm install
npm run dev
```

## Deploy to GitHub Pages

```bash
cd web
npm install
npm run deploy
```

The `deploy` script copies the latest `ai_policy.json` from the repo root into the build before publishing.

## Updating the AI policy

Run `battleship_colab_runner.py` in Colab. It will push an updated `ai_policy.json` to this repo. Re-deploy the web app to pick up the new policy.
